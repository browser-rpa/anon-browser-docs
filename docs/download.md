# 客户端下载

anon-browser 当前以桌面客户端形式提供。下载并安装客户端后，浏览器窗口、Profile 数据和 RPA 任务都在本机管理；客户端不要求先部署服务端才能使用。

## 获取安装包

请从项目发布页下载与你的操作系统和 CPU 架构对应的最新版本安装包。每个版本的发布页会同时提供版本说明和 `SHA256SUMS` 校验文件。

| 平台 | 常见架构 | 安装包形态 |
| --- | --- | --- |
| macOS | Apple Silicon（arm64）、Intel（x64） | `.dmg` 或压缩包 |
| Windows | x64 | 安装程序或压缩包 |
| Linux | x64 | 压缩包 |

如果系统提示无法验证开发者或应用来源，请先确认下载地址和校验值来自同一个正式发布页，再根据系统的安全设置完成确认。不要使用来源不明的二进制文件。

## 安装后第一次使用

1. 启动 anon-browser 客户端。
2. 在“窗口管理”中创建一个窗口，选择 Chrome 版本、设备类型、语言、时区和窗口尺寸。
3. 启动窗口并打开目标网页。
4. 需要自动化时，在“RPA 自动化”中创建、校验、发布并运行工作流。

客户端会在首次需要时准备匹配的 Chrome for Testing 版本。浏览器版本文件由客户端管理，用户不需要手动填写浏览器可执行文件路径。

## 更新与校验

- 升级前请先停止正在运行的窗口和 RPA 任务。
- 不要删除客户端数据目录来解决普通升级问题；窗口数据和工作流由客户端负责管理。
- 如果下载包提供 SHA-256 校验值，建议在安装前进行校验。
- 浏览器版本下载失败时，先检查网络连接和磁盘空间，再重试客户端内置的浏览器准备操作。

本页只说明公开客户端的安装和使用，不涉及服务端部署、远程执行、内部网络组件或数据库结构。
